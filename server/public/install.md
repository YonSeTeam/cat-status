# Кот для Claude Code: установка

Это инструкция для Claude Code. Человек попросил поставить мод «cat-status»:
пиксельного кота над полем ввода, который показывает, что делает Claude, лимиты,
кеш и друзей онлайн. Мод — плагин из функциональных хуков Claude Code.

Перед тем как что-то менять, коротко скажи человеку, что сделаешь (шаги ниже), и
выполняй. Ничего, кроме описанного, не меняй.

1. Скачай архив мода: {{SERVER}}/cat-status.zip
2. Распакуй его так, чтобы получилась папка `~/.claude/mods/cat-status`
   (внутри: `.claude-plugin/plugin.json`, `hooks/register.tsx`, `hooks/hooks.json`,
   `types/index.d.ts`). Если папка уже есть, замени её содержимое: это обновление.
3. Открой `~/.claude/settings.json` (если файла нет, создай `{}`). Добавь в объект
   `"env"` (создай его, если нет) три ключа, не трогая остальные настройки:
   - `"CLAUDE_CODE_PLUGIN_DIRS"`: абсолютный путь к папке `~/.claude/mods/cat-status`.
     Если ключ уже есть и в нём другой путь, допиши этот через разделитель путей
     ОС (`;` на Windows, `:` на macOS и Linux), а не заменяй.
   - `"CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"`
   - `"CLAUDE_CODE_PLUGIN_DIR_WATCH": "1"`
   Проверь, что файл остался валидным JSON.
4. Скажи человеку: перезапусти Claude Code (или открой новую сессию), над полем
   ввода появится кот. Затем:
   - `/cat name <имя>` — как его будут видеть друзья;
   - `/cat color <цвет>` — orange, gray, black, white, blue, pink, green;
   - `/cat server {{SERVER}}` — сервер, через который коты друзей видят друг друга;
   - `/cat friend <код комнаты>` — код ему прислал друг вместе с этой ссылкой.
   `/cat` без аргументов покажет все команды.

Что мод отправляет на сервер {{SERVER}}: имя, цвет, статус (работает / ждёт /
готово / отдыхает), число задач за сегодня, процент 5-часового лимита и время его сброса, настроение
и сколько агентов Claude работает сейчас (столько котят у кота).
Что именно делает Claude («правит main.py») — только если человек сам включит
`/cat share on`.
